# QA Portfolio
This is a QA portfolio to be sent in cover letter.

## SQL
SQL scripts use Chinook DB (https://github.com/lerocha/chinook-database) to provide data for queries.\
DBeaver (https://dbeaver.io/) was used to write queries.\
SQL Lite (https://sqlite.org/index.html) was used as a DB connection type.

## API
Public API under test: https://www.freetogame.com/api-doc, No auth required.\
Requests use Postman (https://www.postman.com/downloads/) for automation.\
Interviewer can export JSONs ([Manual](./API/Postman/portfolioQA_FreeToGame_manual.postman_collection.json), [Automation](./API/Postman/portfolioQA_FreeToGame_automation.postman_collection.json) and [Environment](./API/Postman/Production.postman_environment.json)) for review.\
